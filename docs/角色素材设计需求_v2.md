# 小肥鱼直播间 · 新角色素材设计需求 v2（为抠图而生）

> 上一版素材的教训：品红底与角色色相冲突（紫发尖端/腮红被误判）、半透明尾根无法
> 还原、bloom 光晕污染边缘、薄鳍结构丢失。v2 从设计源头规避全部问题。

## 一、生成流程（两步）

1. **角色设计图**（豆包图片生成）：锁定形象 → 得到一张绿底全身立绘
2. **图生视频**（Seedance）：用设计图作参考图 + 运动提示词 → 生成绿底待机循环视频

## 二、视频硬性要求（缺一不可）

| 项 | 要求 | 原因 |
|---|---|---|
| 画幅 | 1:1 正方形，1080×1080，10~15 秒 | 舞台画布正方形；边缘不裁切 |
| 背景 | **纯绿幕 #00B140**，绝对均匀 | 键控；禁止渐变/暗角/地面阴影/光晕 |
| 光照 | 均匀柔光平光 | 边缘无亮边可抠 |
| 边缘光 | **禁止 rim light / bloom / 辉光** | 上一版毛边元凶 |
| 不透明度 | **全身实体不透明**（尾巴、耳鳍禁止半透明/渐隐/透底） | 半透明=一个方程两个未知数，无法完美还原 |
| 角色配色 | **全身禁用绿色/青绿色**（含耳鳍、瞳孔高光、装饰） | 绿幕键控会吃掉同色角色部位 |
| 构图 | 全身居中，头顶留 8%、脚下留 5%、左右留 10%，不出画不贴边 | 缩放余量 |
| 动画 | 待机循环：呼吸起伏、眨眼、尾巴小摆、手部微动；**首帧=尾帧姿态**（无缝循环）；慢速、无快速动作、无运动模糊 | 循环视频+高抠像质量 |
| 干净 | 无文字、无水印、无道具、无其他角色 | — |

## 三、角色设计（风格延续 v1）

- 蓝紫渐变发色的 Q 版人鱼女孩（头身比 1:1.5 的 chibi 比例），女仆装
- 深蓝连衣裙 + 白围裙 + 蓝色爱心
- **耳鳍改为蓝紫色系**（原青蓝色太接近禁用的绿青）
- 鱼尾：深蓝→浅蓝渐变，**实体不透明**，形状完整（禁止渐隐入背景）
- 头顶挂环保留（轮廓完整）
- 整体色彩：蓝 / 紫 / 白 / 肤色粉，全部与绿幕高对比

## 四、豆包提示词（直接复制）

### 第一步 · 角色设计图

```
生成一张竖构图角色设计立绘：Q版人鱼女孩，头身比约1:1.5，蓝紫色渐变长发双丸子头，
头顶有个小圆环挂饰，精灵鱼鳍耳（蓝紫色），穿深蓝色女仆连衣裙配白色围裙，围裙上
有蓝色爱心，身后一条完整的鱼尾巴（深蓝到浅蓝渐变，实体不透明），站在纯绿色背景
前。要求：背景是绝对均匀的纯绿色绿幕色（#00B140），没有任何渐变、阴影和光效；
全身不透明，边缘清晰锐利；均匀平光照明；人物全身完整入镜，头顶和脚下留出空白
边距；卡通3D渲染风格，质感细腻。
```

### 第二步 · 图生视频（上传第一步的设计图）

```
让这个角色动起来：自然的待机动画，轻微的呼吸起伏，每3秒眨一次眼，鱼尾巴小幅
缓慢摆动，双手偶尔有微小动作，头部轻微晃动。背景保持绝对均匀的纯绿色绿幕
（#00B140）完全不变，没有任何光影变化。角色全程不透明，边缘保持清晰。动作
幅度小且缓慢，没有快速动作。视频首帧和尾帧的姿态完全一致，可以无缝循环。
时长15秒，画面1:1正方形。
```

## 五、交付与验收线

- 拿到视频后跑键控管线（纯绿键控是数学最优情形：色相单一 + 角色色相远离绿色）
- 验收：四角 alpha=0、发丝完整、耳鳍细节完整、尾根实体、首尾循环无跳变
- 跑通待机后，再按同规格补「说话」「开心」两个状态
