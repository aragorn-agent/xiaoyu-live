## 五、七条不变量

1. 所有帧以 `master_final.png` 为唯一身份基准。
2. 所有帧固定同一相机、画布、比例（1024×1024，角色占高 ≥ 92%）。
3. 所有帧固定同一套光照描述（左上主光、右侧冷补光、背后冷轮廓光）。
4. 所有帧过统一色板/LUT；单帧偏色超阈值重生成。
5. 脸由「整头层 + 五官带」锁死，AI 画歪不影响最终脸。
6. 每帧过质检：颜色直方图 + dHash + 运动量 + 头部锚点 + 头部尺度。
7. 运行时只认 `anim.json`，不认文件名；新增动作不改核心代码。

## 六、已知偏差与 P1 处理

| 偏差 | Master 现状 | 目标 | P1 处理 |
|---|---|---|---|
| 尾巴 | 偏人鱼双叉尾 | 水平鲸尾鳍 | 帧 prompt 明确「horizontal whale fluke, not mermaid tail」；仍不行则单独生成尾巴层替换 |
| 裙摆 | 多层蛋糕裙 | 单层外裙 + 一层白荷叶边 | 帧 prompt 明确「single layer, not tiered」；后期可局部重绘 |
| 围裙 | 有胸挡/围兜感 | 简单白色腰围裙 | 帧 prompt 明确「waist apron, no bib」 |
| 袜子 | 及膝长袜 | 白色长袜（可接受） | 保留；参考图本身也是长袜 |
| 蝴蝶结 | 纯色浅蓝 | 纯色浅蓝 | 已符合 |
| 发色 | 深蓝→浅蓝 | 深蓝→浅蓝 | 已符合 |

> 这些偏差不影响 Master 作为「风格 + 身份」基准。P1 生成身体帧时逐条纠正，头部层直接用 Master 裁切。

## 七、生成 prompt

完整 prompt 存在 `master_final.json` 的 `prompt` 字段。核心风格句：

```
HIGH-QUALITY 3D RENDERED CHIBI ANIME CHARACTER, Blender EEVEE,
soft ambient occlusion, subsurface scattering on skin,
glossy eye highlights, subtle cool rim light,
clean edges, high detail, no outline, no cel shading.
```

Negative 里必须常驻：

```
2D flat illustration, cel shading, lineart, character sheet,
multiple views, mermaid tail, polka dots, headphones,
different outfit, different hair color, text, watermark.
```
